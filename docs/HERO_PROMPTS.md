# Race Your Flag: hero build prompts (with heights)

One prompt per hero for rebuilding them in Tripo (image-to-3D). Each one is a single full-body character in an
A-pose, empty hands, so it rigs cleanly. AI tools read heights badly, so every prompt also gives the height
as "heads tall" and body build.

**Keep this list up to date:** when a hero is added or changed, add or update their row in the chart, their
prompt, and their spot in the lineup prompt at the bottom.

## Tripo steps

1. Image-to-3D (or text-to-3D) with the prompt.
2. Retopology: Quad, 10k.
3. Rig: Humanoid, Mixamo preset.
4. Export GLB and send it over.

Note for the game: it currently sizes every 3D hero to the same height. When the new models arrive, the
loader needs a small change to keep each model's own height (see HANDOFF.md).
