# Parked for later (Oct 17)

## Heroes taken out of the game
Only the 7 launch heroes stay: Kapwa Lamò, Blake Carter, Aria Windsong, Hayato Kurogane, Malkia Nyota, Kid Echo, Ha-Neul.
Removed for now: **Sir Aldric (knight), Xiao Long (shaolin), Sigurd Stormbeard (viking), Volt-X (robot), Zuri Vapor (gas)**.
- Their full code (hero entries, story, speech lines, 3D model entries) is saved in `docs/parked/heroes.js`.
- Their 3D models are still in `models/` (`knight.glb`, `shaolin.glb`, `viking.glb`, `robot.glb`, `gas.glb`).
- Their power effect code is still inside `index.html`, so putting a hero back only needs the saved entries pasted in.
- The plaza rivals that used them now use launch heroes.

## Recolor-only skins
These painted the whole model one colour (face included), so they are hidden until each hero has real 3D skins.
The list is in `docs/parked/skins.txt`; the code keeps them as `SKINS_PARKED` in `index.html`.
